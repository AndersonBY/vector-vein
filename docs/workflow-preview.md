# 工作流画布预览

模板详情中的“预览画布”、工作流选择列表标题旁的眼睛按钮，以及工作流选择节点的候选条目，都可打开只读预览。点击预览不会选择候选工作流。

预览显示节点的自定义或本地化名称、连接端口和连线，保留原有位置。已忽略的节点淡化显示，相关连线使用虚线。空工作流显示空态；无法识别的节点类型使用原类型名称。

可拖动画布、滚轮缩放，或使用放大、缩小、适应画布按钮。预览仅展示结构，不载入实际节点编辑器或字段值。预览画布与主编辑器各自维护视口；关闭预览不会改变工作流、运行记录或编辑器撤销历史。

从工作流列表打开时会读取最新定义，加载失败可重试。模板详情使用当前已加载的定义。关闭弹窗、切换工作流或离开页面后，过期请求的结果不会显示。

## GUI 验收

1. 在模板详情打开预览，检查节点和连线，并验证缩放、平移和适应画布。
2. 在工作流选择列表预览一个条目，再关闭弹窗，确认没有触发选择或添加。
3. 在工作流选择节点中预览已有候选，确认主编辑器节点位置、字段和撤销历史没有改变。
4. 检查空画布、忽略节点和自定义节点名称；读取失败后重试。
