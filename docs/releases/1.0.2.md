# VectorVein Desktop 1.0.2

This release includes the 1.0 features, automatic protection for legacy data, and cross-platform release validation fixes.

- Background-command tests read structured terminal metadata and verify confirmed termination.
- Skill import tests exercise Windows junctions and POSIX symbolic links on their respective platforms.
- Knowledge bridge tests check whether optional loopback aliases exist before binding, while validating address routing on every platform.
- Windows tray tests use isolated icon resources and verify the native-window fallback before the frontend is built.

## Upgrade notice / 升级说明

**Exit the old application (including its system tray process) before starting the upgrade. Existing installations are backed up automatically before migration.** The application creates a verified ZIP beside the configured data directory, preserving the complete tree, original settings, attachments and committed SQLite/WAL data. Backup failure stops the upgrade; it does not proceed with deleting legacy conversation data.

**请先退出旧版程序（包括系统托盘进程）。旧版升级会先自动备份，再迁移。** 程序会将原数据目录完整压缩为同级 ZIP，保留原始设置、附件及 SQLite/WAL 已提交的数据。只有备份校验成功才继续；磁盘空间、权限、文件变化或校验错误都会中止升级。

For a directory named `data`, the archive is named `data-backup-before-v1.0.0-<timestamp>-<id>.zip`. Custom data directories use their own name and parent directory. Archives stay local and are never overwritten. A valid backup is reused only while the original data is unchanged; after a successful migration, normal starts do not create more backups.

备份完成后，旧对话 Agent 与历史记录会从活动数据库移除，但原始记录仍在 ZIP 中。若需要恢复旧版数据，请退出所有 VectorVein 进程，保留当前数据目录，再将备份解压到原父目录，并使用对应旧版本打开。重新用 1.0 系列启动会再次执行迁移。备份包含原数据和设置，请妥善保管。

Existing relational databases remain available; legacy vector datasets are imported into knowledge bases and may require explicit reindexing for semantic retrieval.

## What's new

- Task Agents with durable history, background startup, runtime model and permission settings, Bash, subagents and configurable LLM-assisted approval.
- Projects with one or more local directories; task workspaces respect each Project's selected roots.
- Skills and MCP management, including importing Skills from common local Agent directories.
- Scheduled Agent tasks and reusable schedule/Agent/task selectors. Runs can create new tasks or continue an existing task, with optional hiding and desktop notifications.
- Knowledge bases with hierarchical files, extraction, indexing and scoped retrieval. Mounted documents are available through ordinary file tools at read-only `.knowledge/` paths, including PDF and Office extracted text.
- Embedding and reranking configuration, connection tests and local Vekai service presets.
- System-tray support, configurable window-close behavior, clearer errors, reusable model pickers and compact action buttons.
- DeepSeek web-search configuration and workflow support; retired Bing API search configuration removed.

## 主要更新

- 任务 Agent：持久化历史、快速进入详情页、运行时模型与权限调整、Bash、子代理及可配置的 LLM 风险审批。
- 多目录 Project、Skills/MCP 管理，以及从本机常见 Agent 目录导入 Skill。
- Agent 定时任务：新建或继续已有任务，可配置完成后隐藏及桌面通知。
- 层级知识库、文档处理与检索，以及普通文件工具可访问的只读 `.knowledge/` 虚拟目录。
- 嵌入与重排序模型配置、连接测试、Vekai 本机服务接入。
- 系统托盘、关闭窗口行为设置、模型选择器及任务界面优化。

## Packages

The release workflow builds Windows, macOS and Linux ZIP packages and validates the packaged CLI and Agent runtime. The macOS package follows the configured `macos-latest` runner; there is no separate Intel macOS build in this release matrix.

Models and API credentials are configured by the user. Local Vekai must be started separately; it is not bundled with VectorVein.
