# VectorVein Desktop 1.0.0

## Upgrade notice / 升级说明

**This is a breaking major release. Back up the application's `data` directory before upgrading if you need your old conversation history.** The retired conversation Agent module, conversations and messages are permanently removed by the 1.0 migration. Task Agent is now the primary interface. Existing relational databases remain available; legacy vector datasets are imported into knowledge bases and may require explicit reindexing for semantic retrieval.

**这是一次不兼容的大版本升级。如需保留旧对话历史，请在升级前备份程序的 `data` 目录。** 1.0 迁移会永久删除旧对话 Agent、对话及消息记录。任务 Agent 成为主要工作入口。关系数据库继续保留；旧向量数据集会导入知识库，语义检索可能需要手动重建索引。

## What's new

- Task Agents with durable history, background startup, runtime model and permission settings, Bash, subagents and configurable LLM-assisted approval.
- Projects with one or more local directories; task workspaces respect each Project's selected roots.
- Skills and MCP management, including importing Skills from common local Agent directories.
- Scheduled Agent tasks and reusable schedule/Agent/task selectors. Runs can create new tasks or continue an existing task, with optional hiding and desktop notifications.
- Knowledge bases with hierarchical files, extraction, indexing and scoped retrieval. Mounted documents are available through ordinary file tools at read-only `.knowledge/` paths, including PDF and Office extracted text.
- Embedding and reranking configuration, connection tests and local Vekai service presets.
- System-tray support, configurable window-close behavior, clearer errors, reusable model pickers and compact action buttons.
- DeepSeek web-search configuration and workflow support; retired Bing API search configuration removed.

## 主要更新

- 任务 Agent：持久化历史、快速进入详情页、运行时模型与权限调整、Bash、子代理及可配置的 LLM 风险审批。
- 多目录 Project、Skills/MCP 管理，以及从本机常见 Agent 目录导入 Skill。
- Agent 定时任务：新建或继续已有任务，可配置完成后隐藏及桌面通知。
- 层级知识库、文档处理与检索，以及普通文件工具可访问的只读 `.knowledge/` 虚拟目录。
- 嵌入与重排序模型配置、连接测试、Vekai 本机服务接入。
- 系统托盘、关闭窗口行为设置、模型选择器及任务界面优化。

## Packages

The release workflow builds Windows, macOS and Linux ZIP packages and validates the packaged CLI and Agent runtime. The macOS package follows the configured `macos-latest` runner; there is no separate Intel macOS build in this release matrix.

Models and API credentials are configured by the user. Local Vekai must be started separately; it is not bundled with VectorVein.
