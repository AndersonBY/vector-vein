# 模型端点测试

模型设置和端点编辑窗口提供实际请求测试。测试使用当前表单中的端点草稿、模型 ID 和测试消息，发送一次非流式模型请求；模型的端点配置弹窗默认消息是 `Hi`，独立端点编辑窗口为 `Hi!`。修改地址、密钥、自定义请求头或代理后，可以先测试，再决定是否保存设置。测试本身不保存端点，也不修改已保存的模型配置或 vv-llm 全局设置。

请求通过当前后端对应的 vv-llm 客户端创建，使用提交的单个端点和模型。测试不会切换其他端点，也不会从主机环境变量补充 API 密钥、账户信息或代理。OpenAI 兼容的匿名端点可以留空 API 密钥；需要原生认证的适配器要求表单提供相应凭据。

每个 HTTP 阶段使用 20 秒超时，关闭 SDK 自动重试。成功时显示模型的文本回复；服务提供独立推理字段时，同时显示推理内容。输入无效、认证失败、服务错误或网络异常会显示原因，并结束加载状态。再次测试会清除上次结果；切换端点、模型或消息后，旧请求晚到的结果不会覆盖新状态。

## 模型端点优先级

每个模型的端点绑定可以配置优先级和独立的模型 ID。优先级必须是大于或等于 1 的整数，数值越小越优先；同级按列表顺序选择，可以用上下移动按钮调整。旧的字符串绑定和未配置优先级的绑定均按优先级 1 处理。禁用或不存在的端点不参与选择。工作流的“仅首选端点”策略也按优先级选择首个可用端点。

端点弹窗内点击确定仅更新模型草稿；取消会丢弃该弹窗的修改。模型确认后，还需保存设置才会持久化。编辑已有端点会替换原条目，并保留未展示的绑定配置。临时测试始终只请求弹窗当前选择的单个端点，不受列表优先级影响。

## 模型能力

聊天、Agent 和工作流的模型选择处显示图片输入、原生工具、JSON 模式及上下文、最大输出限制，均来自已有模型配置；缺失值显示未知。工作流请求不支持的原生工具、JSON 模式或图片输入时，会在模型或图片网络请求前明确报错；显式输出上限不能超过已配置的上下文和最大输出限制。本地输出 Schema 校验独立于原生 JSON 模式，聊天的提示词工具兼容行为保持可用。

## API

调用设置 API：

```javascript
settingAPI('test_model_endpoint', {
  backend: 'openai',
  endpoint: {
    id: 'draft-endpoint',
    api_base: 'http://127.0.0.1:8000/v1',
    api_key: '',
    headers: {},
    proxy: null,
  },
  model_id: 'draft-model',
  message: 'Hi!',
})
```

成功返回 `status: 200`，`data.content` 为文本回复，可选的 `data.reasoning_content` 为推理内容。输入问题返回 `400`；模型服务和传输错误返回 `502`，`msg` 提供经过凭据遮盖的错误信息。模型 ID 和消息不能为空，消息长度最多 8000 个字符，API base 必须是有效 HTTP 或 HTTPS URL。

原生 Anthropic 和 Azure 端点要求显式 API key。Bedrock 端点要求显式 access key、secret key 和 region；可选 session token 也来自草稿。Vertex 测试要求显式 credentials、project、region 和有效期还剩五分二十秒以上的 access token，以避免通过测试自动读取主机认证或触发额外的令牌获取流程。

## 手工验收

使用 [独立目录启动步骤](workflow-failures.md#在独立目录启动手工验收) 启动当前检出的应用。若使用本机模拟端点，将其地址、模型 ID 和合成密钥填入表单即可，无需真实模型账户。

1. 在设置中编辑端点，输入一个尚未保存的地址和模型 ID。保持默认 `Hi!` 并点击测试，确认显示实际响应。将消息改为一段中文再次测试，确认响应对应新消息。
2. 修改尚未保存的自定义请求头或 API key 后测试，确认服务收到草稿值。关闭编辑窗口但不保存，再次打开，确认测试没有更改已保存设置。
3. 切换到错误的模型 ID、错误密钥或无法连接的地址。确认显示具体错误、加载结束，旧的成功回复被清除；修正后可以再次测试。
4. 清空模型 ID 或消息后测试，确认显示输入提示且不发出模型请求。选择其他端点时，之前的响应应清除。
5. 在请求尚未完成时切换端点或修改消息。确认原请求返回后不会显示在新草稿下。若服务返回 `reasoning_content`，确认它与正文分别显示。

## 自动化验证

从空的临时工作目录运行以下测试，使用已安装项目依赖的解释器，并将 `<仓库>` 替换为当前检出的绝对路径：

```text
python -m pytest <仓库>/backend/tests/test_llm_endpoint_test.py <仓库>/backend/tests/test_llm_endpoint_test_integration.py -q
```

独立集成测试使用真实 vv-llm/SDK 客户端连接本机 HTTP 服务，核对并发草稿的地址、模型、消息和请求头，检查已保存设置及全局设置保持不变，并通过本机 HTTP 代理验证服务错误脱敏。原生 Anthropic 请求也验证路径、显式密钥和正文及推理内容提取。测试只使用合成凭据，不调用真实模型服务。
