# HTML 结果预览

工作流运行页和聊天中的历史工作流结果共用 `HtmlPreview`。预览区提供放大查看、Esc 还原和加载失败后的重试；放大时保留同一个 iframe，页面内的交互状态不会重置。

HTML 节点执行期间只显示一个预览加载状态，完成后再读取新输出。读取或页面加载超过 30 秒会结束等待并提供重试。切换来源、重试或卸载组件时取消旧请求、释放 Blob URL，过期响应不会覆盖当前结果。

组件通过 HTTP(S) 读取 HTML，不携带应用凭据，再以 HTML MIME 的 Blob 显示。文档的 base 地址来自实际响应 URL；已有的相对 base 按该地址解析，图片、样式和脚本的相对路径仍指向原文件位置。预览 iframe 允许页面脚本，使用独立来源，不能访问桌面应用的父页面接口。

本地文件服务生成 URL 时统一 Windows 路径分隔符并编码中文、空格、`#`、`%`、`?`。请求路径仅解码一次，查询参数不属于文件名。普通旧版 Windows 路径 URL 仍可使用；旧 URL 中未编码且已被浏览器截断的 `#`、`?` 无法从剩余 URL 恢复。

文件缺失或移动后显示加载失败。历史结果仍读取该路径当前的文件内容，不复制或版本化文件。远程 HTML 地址需要允许跨域读取；相对资源由原站的访问规则决定。

测试覆盖见 `frontend/tests/htmlPreview.test.js` 和 `backend/tests/test_static_file_server.py`。
